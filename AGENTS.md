# Online Food Ordering Project

## Business Requirements

- An MVP of a web app for managing grocery purchasing - the idea is to replace a spreadsheet for tracking groceries and shopping lists
- The web app should have a dashboard with filters for showing different subsets of groceries like produce, pantry, freezer, household, etc.
- The user should be able to enter and update the prices of groceries at different stores in an effort to find the best prices.
- The user should be able to enter the current inventory of each item in their home so they can keep track of what they have and what they need to buy.
- The user should be able to create shopping lists based on their inventory and desired purchases.
- The user should be able to mark items as purchased and update their inventory accordingly.
- When the user first visits the app, they should be able to enter a list of their common grocery items to quickly set up their inventory.


## Technical Details

- Implemented as a ReactJS front end with a NodeJS backend and a SQLite database to begin with, but the database can be swapped out for a more robust solution later
- Use popular libraries
- As simple as possible but with an elegant UI
